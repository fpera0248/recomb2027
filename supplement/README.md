# Supplement analyses

These are the scripts behind the supplement analyses that `reproduce.sh` does not run. They cover the further analyses of the duplication study (Supplementary Section S7) and the further analyses of the hidden-subtype study with Figure S5 (Supplementary Section S17). Each file is a copy of a script we ran. Only comments, docstrings and path defaults were edited (paths now read `HR_WORK`, `SUPP_DATA`, `GF_ROOT`), with defaults that resolve to the original paths, except that `further/embeddings/gfcfg.py` reads the cell list from `GF_CELLS_CSV`, which has no default because the original was a temporary file that was not released. One non-ASCII string literal in `figures/figS_further.py` was also written as an escape. The code is otherwise unchanged. Most produced printed numbers. The rest are the helpers, queues and checks they need. For the S7 paragraph on HLCA, `duplication/m27_hlclf.py` (`run`, then `report`) scored the generated cells. The scripts that generated them are not here.

The scripts do not run from this repository alone. Paths inside them default to folders under `~/work` and `~/data` on our machines and the external volume `/Volumes/Files`; set `HR_WORK` to move `~/work`, `SUPP_DATA` to move `~/data` and `GF_ROOT` to move `~/geneformer/Geneformer`. `SUPP_DATA` is unrelated to the `HR_DATA` of the main pipeline. Some scripts also call `$HOME/venv` interpreters. Most read inputs that we did not release: the AIDA, HLCA and lupus files, the generated cells and the subsamples of the 10-atlas set. Read them as a record of what we ran. File and directory names carry our working codes, which are the module and file names the scripts load from our original working tree, so they are kept: `sr3`, `sr3m`, `sr3h` (candidate groups, marker and halo features), `learn14` and `m14p` (the learned scorer), `m1_leiden_sub` (Leiden subclustering), `m1` to `m8` (the early detectors), `m10` (split-island detector), `m11` (the seprank baseline), `m15x` (rank-combination variants), `frozen4` (the final blend, "our method" in the paper), `build_atlas5` and `build_r5` (the pool builders for the test atlases), `r5` and `test5` (the test-atlas work folder and split name). Names in the duplication study and the further analyses: `m27` (the donor-disjoint duplication runs), `gen12`, `gen14`, `gen16` (the generator experiments; comments that cite other numbers from `gen5` to `gen15` refer to earlier generator experiments that are not included), `mk16` (saved arm cells), `j21` and `ref_j21` (the one-versus-rest runs and their saved reference metrics), `run_e1` (the one-versus-rest metrics driver), `w1_scale` and `scale_pipeline` (scaling), `w2_*` and `w2lib` (the embedding analysis), `w6*` and `analyze_w6` (the label-corruption analysis), `r3c_matched` (annotation improvement at a matched number of classes), `p1_panel_stats` and `panel_analysis` (the CELLxGENE panel), `fm` and `foundation_models` (foundation-model duplication). `D1` and `D2` are the development pilot designs and `D1null` their null versions (used in `further/method_at_submission/`). Path defaults and comments also name folders of the original working tree: `jiaqi1011`, `j1004`, `rev1015`, `monday_q`, `recomb27`, `cfgen_natrare`, `w1`, `jiaqi1016`, `E2_major_types`, `opus_check` (under `tmp/`), `figaudit`, `hvg1015`, `hvg_c3`, `donorfix`, `src_mini`, `from_mini`, `p1data`, `si_v3`, `vm3_m12`, `r4_out`, `v4_integ`, `w6_annot_atac`, `scale_data`, `aida_sg`, `ablation_donor`, `gf6l_emb`, `recomb2027-r8i3wt`, `recomb2027-assets`, and the files `selection_amend2.txt` and `cand_api.json`; the defaults still point to them under `HR_WORK`. `BC1` to `BC4` and `check N` in `build_r5.py` are its build-check status keys.

## Shared code

- `duplication/` holds the helpers that the scripts import: `stat16.py` (classifiers and matched recall), `polh.py` (the sign-flip test), `sdiff_mod.py` (our scDiffusion wrapper), `m27_hlclf.py` (classifiers for AIDA, HLCA and lupus), `metrics/common.py` (data loading for `run_e1.py`) and `mem_patch.R` (a memory patch for scDesign3). `m27_gen_base.py` writes the saved cells of the eight usual types that later scripts read.
- `further/method_at_submission/` is our method as it stood when we ran the further analyses, which import it. `hiddenrare/` at the repository root is the released version.
- `further/embeddings/`, `further/labels_and_atac/` and `further/scale_and_regressors/` also hold shared helpers: `harness.py`, `w2lib.py`, `w6common.py`, `gfcfg.py` and `gfload.py` (Geneformer loading for `w2_embed.py`), `w2_common.sh` (sourced by the w2 queues), `laptop_lock_run.sh` (a lock wrapper that `w2_fm_gf.sh` and `w2_fm_plumb.sh` run) and the pool lists.
- `further/queues/` holds the shell scripts that ran the jobs in order.

We did not copy third-party code. CFGen, scDiffusion and Geneformer load from clones of the authors' repositories. scGPT and scvi-tools come from pip, and scDesign3 and snapATAC2 are installed packages.
