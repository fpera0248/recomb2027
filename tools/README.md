## Published tools

Run the commands from the repository root.

`tools/sources.txt` lists the official repositories and commits; `tools/fetch_sources.sh` clones them into `$TOOLS_SRC`. The wrappers in `tools/` only adapt input and output, except that `run_cellsius.R` patches one type test of the CellSIUS function in memory so it runs on R>=4.2 (`class(mat.norm) != "matrix"`). `run_cellsius.R` on the 2,000 variable genes of `tools/adapt_pool.py` gave the CellSIUS (per label) scores of Fig. 3a; the later all-gene CellSIUS run of the supplement reached the 32 GB memory limit and has no result. R tools need Seurat 4.4.0 / SeuratObject 4.1.4. The `recomb2027-tools` image (`docker/Dockerfile.tools`) installs all of this; `Rpackages_tools.csv` and `piplist_tools.txt` are the exact package sets of the environment the tools ran in.

Python tools run in their own Python 3.12 environment (set `TOOLS_PYTHON` for `scripts/run_tool.sh` and `reproduce.sh full`; the pins come from a macOS arm64 environment; R steps in `ENVIRONMENTS.md`, Manual build): `pip install --extra-index-url https://download.pytorch.org/whl/cpu -r tools/requirements.txt; pip install --no-deps $TOOLS_SRC/GiniClust3 $TOOLS_SRC/scGPT`; build FiRE by copying `python/FiRE` of its checkout and `tools/fire_setup.py` (as `setup.py`) into `FIRE_BUILD` and running `python setup.py build_ext --inplace` there (Boost headers needed); set `SCGPT_CKPT` to the scGPT whole-human checkpoint dir and `MCL` to the mcl binary (CellSIUS; Debian and Ubuntu package `mcl`). `$TOOLS_SRC/scCAD/scCAD.py` must have md5 a0865c37513aaee5eae13551e48da6f2 (`tools/fetch_sources.sh` checks this). The reported scGPT run used `DEVICE=mps`.

`run_giniclust3.py` applies no gene or cell filter and uses 5 neighbors (the paper's GiniClust3 (no filters, 5 neighbors)); it does not regenerate the GiniClust3 (swapped filters) rows, whose runner is not included.
